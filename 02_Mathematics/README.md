# Mathematics

A collection of notes and resources covering the core mathematical foundations needed for data science, machine learning, and programming — organized into four main areas.

## 📖 Overview

This folder is meant to serve as a structured reference for the math concepts that underpin data analysis, statistics, and machine learning. Each subfolder focuses on a specific branch of mathematics, building from foundational statistics and algebra up to more advanced statistical topics.

## 📂 Contents

| Folder | Overview |
|---|---|
| `Advanced Statistics` | More in-depth statistical concepts beyond the basics — e.g. hypothesis testing, distributions, regression analysis, and statistical inference. |
| `Calculus` | Core calculus concepts — limits, derivatives, integrals, and their role in optimization and machine learning (e.g. gradients). |
| `Linear Algebra` | Vectors, matrices, matrix operations, eigenvalues/eigenvectors, and their applications in data science and ML. |
| `Statistics & Probability` | Fundamentals of probability theory and descriptive/inferential statistics — mean, variance, probability distributions, and more. |

## 🎯 Purpose

- Build a solid mathematical foundation to support data science and machine learning work.
- Keep concepts organized by branch for easy reference.
- Bridge theory with practical, applied examples where possible.

## ✅ How to Use

1. Start with `Statistics & Probability` and `Linear Algebra` if you're building foundational knowledge.
2. Move to `Calculus` to understand optimization concepts used in machine learning.
3. Use `Advanced Statistics` once comfortable with the basics, to dive deeper into inference and modeling techniques.
