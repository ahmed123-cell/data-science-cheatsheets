# Python Fundamentals

A personal collection of Python notes and code examples covering fundamental concepts, built-in data types, functions, iteration, object-oriented programming, standard libraries, unit testing, and database connectivity.

## 📖 Overview

This folder serves as a quick reference and practice resource for learning Python. Each file focuses on a specific set of related concepts, with inline comments, docstrings, and example outputs (`# --> result`) to make the code easier to understand, review, and practice.

## 📂 Contents

| File | Overview |
|---|---|
| `00_python_basics.py` | Python syntax, variables, basic data types, and fundamental programming concepts. |
| `01_data_types_and_methods.py` | Built-in data types, including strings, numbers, lists, tuples, dictionaries, and sets, along with their common methods. |
| `02_functions.py` | Function definitions, parameters, arguments, return values, and variable scope. |
| `03_loops_and_iteration.py` | Loops, iteration techniques, and tools for traversing and processing data. |
| `04_essential_python_concepts.py` | Modules and imports, iterators and iterables, generators, decorators, docstrings, type hints, and common Python errors. |
| `05_exceptions_and_file_handling.py` | Exception handling with `try` and `except`, raising exceptions, and reading and writing files. |
| `06_object_oriented_programming.py` | Object-oriented programming concepts, including classes, objects, attributes, methods, inheritance, and related principles. |
| `07_standard_library.py` | Useful modules and tools from Python's standard library. |
| `08_testing_and_database_connectivity.py` | Unit testing, test organization, database connections, and related examples. |
| `utils.py` | Reusable helper functions shared across scripts, if applicable. |
