# Power BI

A collection of notes, DAX formulas, and sample visual projects for learning **Power BI** — Microsoft's business intelligence and data visualization tool.

## 📖 Overview

This folder focuses on building practical Power BI skills, from writing DAX (Data Analysis Expressions) for calculations and measures, to designing and building interactive visuals and dashboards using real datasets.

## 📂 Contents

| Folder / File | Overview |
|---|---|
| `DAX/` | Notes and examples on DAX (Data Analysis Expressions) — formulas, measures, and calculated columns used for data modeling and analysis in Power BI. |
| `Visuals/` | A sample Power BI project demonstrating how to build and style visuals/dashboards. |
| `Visuals/Visuals.pbix` | The Power BI project file containing the report, visuals, and data model. |
| `Visuals/Visualization_guide.md` | Notes explaining the approach/workflow used to build the visuals in this project. |

## ▶️ How to Use

1. Install **Power BI Desktop** (Windows only) from the [official Microsoft site](https://www.microsoft.com/en-us/power-platform/products/power-bi/downloads).
2. Open `Visuals/Visuals.pbix` in Power BI Desktop to explore the report and visuals.
3. Review `Visuals/Visuals_way.md` for notes on how the visuals were built.
4. Check the `DAX/` folder for formula examples and explanations you can reuse in your own reports.
