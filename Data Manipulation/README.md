# Data Manipulation

A collection of Python scripts covering data manipulation fundamentals using **NumPy** and **Pandas** — two of the most essential libraries for working with data in Python.

## 📖 Overview

This folder focuses on learning how to efficiently handle, transform, and analyze data using arrays (NumPy) and dataframes (Pandas). The scripts include practical examples to build a solid foundation before moving into data analysis or machine learning.

## 📂 Contents

| File | Overview |
|---|---|
| `numpy_tutorial.py` | Introduction to NumPy — arrays, array operations, indexing/slicing, reshaping, and mathematical functions. |
| `pandas_tutorial.py` | Introduction to Pandas — Series, DataFrames, reading/writing data, filtering, and basic data analysis operations. |

## ▶️ How to Run (Using Jupyter Notebook)

Since these scripts are meant to be explored interactively, running them through **Jupyter Notebook** lets you see results instantly, cell by cell, instead of running the whole file at once.

1. **Install Jupyter** (if not already installed):
   ```bash
   pip install jupyter
   ```

2. **Install NumPy and Pandas**:
   ```bash
   pip install numpy pandas
   ```

3. **Launch Jupyter Notebook** from this folder:
   ```bash
   jupyter notebook
   ```

4. Create a new notebook (`.ipynb`) or convert an existing `.py` file into notebook cells, then run each cell individually (`Shift + Enter`) to see the output right away.

> 💡 Tip: You can also open these `.py` files directly in **VS Code** and use the "Jupyter" extension, which lets you run `# %%` cell blocks interactively without needing a separate `.ipynb` file.
