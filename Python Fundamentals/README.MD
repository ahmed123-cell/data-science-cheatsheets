# Python Fundamentals

A personal collection of notes and code examples covering the core building blocks of Python — from basic syntax to more intermediate concepts like iterators, generators, decorators, and type hinting.

## 📖 Overview

This folder is meant to serve as a quick-reference and practice ground while learning Python. Each file focuses on a specific set of related concepts, with inline comments and example outputs (`# --> result`) to make the code self-explanatory.

## 📂 Contents

| File | Overview |
|---|---|
| `00_python_fundamentals.py` | The very basics of Python — syntax, variables, data types, and getting-started concepts. |
| `01_types_methods.py` | Built-in data types (strings, numbers, lists, tuples, dicts, sets, etc.) and their common methods. |
| `02_functions.py` | Defining and calling functions, parameters, arguments, return values, and scope. |
| `03_iteration_tools.py` | iteration-related tools/utilities for traversing data. |
| `04_core_concepts.py` | Modules & Imports, Iterators & Iterables, Generators, Decorators, Documentation (docstrings), Type Hinting, and Common Python Errors. |
| `05_exception_&_file_handling.py` | Handling errors with `try`/`except`, and reading/writing files. |
| `06_python_OOP.py` | Object-Oriented Programming — classes, objects, inheritance, and related concepts. |
| `07_standard_libraries.py` | Working with Python's built-in standard library modules. |
| `helper_functions.py` | Reusable utility/helper functions used across the other files. |

## 🎯 Purpose

- Reinforce Python fundamentals through hands-on code.
- Build a searchable personal reference for future projects.
- Keep concepts organized in a clean, structured format.
